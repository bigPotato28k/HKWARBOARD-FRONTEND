
## Start here

1. Copy `.env.example` to `.env.local`.
2. Run `npm install`.
3. Run `npm run dev` for local development, or `npm run build` followed by `npm start` for production.
4. Apply the small server changes in [`backend-render-changes/README.md`](./backend-render-changes/README.md) before switching SSE on.

For plain-language setup and deployment instructions, open [`docs/BEGINNER-GUIDE.md`](./docs/BEGINNER-GUIDE.md).
